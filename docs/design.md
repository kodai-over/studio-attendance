# デザインの決まり

LINE内アプリ・参加リンクのページ（`apps/liff`）の見た目と動きの決まりです。
画面を足したり直したりするときは、ここに沿って作ります。決まりにない見た目が要るときは、先にこの文書を直してから使います（直し方は最後にあります）。

## 目指す姿

- **白と黒を基本に、余白を広く。** 情報を詰め込まず、1つのまとまりに1つの役割を持たせる。
- **色は意味のある所だけ。** 未定・期限間近・中止・土日・未回答の件数など、知らせたいことがある所にだけ色を使う。飾りのための色は使わない。
- **チケットがこのアプリの顔。** 予約情報は、左に日付の半券、切り込みと点線のあるチケットで見せる。ここだけは個性を残す。
- **動きは、画面を広く使うためと、押した手応えのためだけ。** 目を引くための動きは足さない。
- **説明は短く。** 「※」で始まる注意書きや、何行もの説明文は書かない。1文で足りるように画面の作りで伝える。

## 決まりの値（トークン）

値は [styles.css](../apps/liff/src/styles.css) の先頭（`:root` とダークの塊）でだけ決め、ほかの所では `var(--…)` で使います。
ライト／ダークの切り替えは、この塊の値を変えるだけで済むようにします。

### 色

| 名前 | 使う所 |
| --- | --- |
| `--bg` | 画面の背景 |
| `--surface` / `--surface-2` | まとまり（カード・一覧・入力欄）の面と、その中の一段濃い面 |
| `--text` / `--text-2` / `--text-3` | 本文 / 補足・ラベル / 薄い文字（無効・プレースホルダー） |
| `--separator` | 区切り線（使う所は最小限に） |
| `--accent` / `--on-accent` | 主な操作・選択中（白黒）と、その上の文字 |
| `--warning` / `--on-warning` | 未定・キャンセル期限間近・未保存の下書き |
| `--danger` | 中止・削除・エラー |
| `--success` | 最低人数に届いた |
| `--sat` / `--sun` | 土曜 / 日曜・祝日 |
| `--badge` / `--on-color` | 件数の赤い丸と、色の上の白い文字 |

新しい色は足さないのが基本です。どうしても要るときは、意味（何を知らせる色か）を決めてトークンとして足します。

### 余白・角丸・文字・影

- **余白**：4px 刻みの `--sp-1`（4）〜`--sp-12`（48）。画面の左右は `--pad-x`、カードの内側は 16px、カード同士は 12px、まとまり同士は 32px が目安。
- **角丸**：`--r-sm`（8：入力欄・小さいボタン）、`--r-md`（12：カード・一覧・チケット）、`--r-lg`（20：ダイアログ）、`--r-full`（丸いボタン・チップ）。
- **文字**：`--fs-2xs`（11）〜`--fs-3xl`（32）。本文は 15px（`--fs-md`）。太さは 400 と 600（大きい見出しだけ 700）。入力欄は iPhone で拡大されないよう `--fs-input`（16）。
- **影**：原則なし。浮いているもの（下のメニュー・トースト・ダイアログ）だけ `--shadow`。

## 部品

新しい部品を作る前に、ここにあるものを使います。見た目の違う同じ役割の部品を増やしません。

| 役割 | クラス・部品 | 決まり |
| --- | --- | --- |
| 画面の上部 | `TopBar` | メニューから開く画面は大きい見出し（28px）。戻るがある画面はバーの中央に小さく出す。大きい見出しの画面では、ボタンは見出しと同じ高さの右端に置く。スクロールして見出しが隠れたら上のバーに移る |
| まとまりの見出し | `.sec-head` | 小さい灰色の見出し。画面の中の大きな区切りだけ `.sec-head.big` |
| ボタン | `.btn` | 主な操作は `primary`（1画面に1つが目安）、ほかは無印（面の色）、文字だけは `plain`、削除は `danger`。高さ 44px、小さいものは `small` |
| 一覧 | `.menu` / `.menu-row` | 設定アプリのような、面の上に行を並べる一覧。行の高さは 48px 以上 |
| 切り替え | `Tabs` | 2〜3個の切り替えは分段コントロール |
| 選ぶ | `.chip` | グループなどを選ぶ丸いチップ。選ぶと黒く反転 |
| 状態の印 | `.label` | 満員・中止・最新などの小さな印。色付きは `danger` / `warning` だけ |
| 件数 | `.count-badge` | 未回答の件数などの赤い丸 |
| 注意の帯 | `.banner` | 未回答の案内・未保存の下書きなど、今すぐ見てほしいこと |
| 補足の文 | `.note` | 1文で。「※」は付けない |
| ダイアログ | `.overlay` + `.dialog` | 確認・処理中の表示 |
| 予約情報 | `PracticeCard` / `Stub` | 半券・切り込み・点線のチケット。中身は 時刻／場所／人数と金額／予約者とキャンセル期限 |
| 曜日絞り込みチップ | `.filter-chip` | 平日・休日を絞り込む丸い小型チップ。選ぶと反転 |
| 絞り込み適用中タグ | `.filter-tag` | 絞り込みが有効なときに表示される解除ボタン付きタグ |
| 日付選択バー | `.selected-date-banner` | カレンダーで日付選択中に表示される解除ボタン付きの案内バー |
| 月・週見出し | `.schedule-group-head` | 月・週単位で予約情報を折りたたむ見出しボタン |
| 詳細の右側の並び | `.detail-side > * + *` | 参加者・ゲスト・参加リンク・募集を送る・編集の間は、すべて同じ間隔（`--sp-5`）。まとまりごとに余白を足さない |
| ゲストの追加 | `.guest-add` | めったに使わない操作は、ふだんは小さな文字ボタン（`.btn.plain.small`）だけにして、押すと入力欄が出る。見出しは付けない。参加者のすぐ下に置く |
| 選べるチケット | `.pick-row` / `.pick-mark` / `.pick-bar` | 「募集」の一覧で「選ぶ」を押すと、チケットの右上に丸いチェックが付き、押すと選ぶ／外す。選べないもの（満員・未募集など）は薄くする。選んだ数は下に浮かぶ主ボタン（`.pick-bar`）に出し、押すと送り先のグループを選ぶダイアログが開く。選ぶ操作は、登録の＋と同じアイコンボタン（送信アイコン。選んでいる間は×）で右上に並べる |

## チケット

- 左の半券に月・日・曜日。土曜は青、日曜・祝日は赤の淡い面。「行く」と答えると半券が黒く反転し、「未定」は左に色の線。
- 本体の行は 時刻（と状態の印・自分の回答）、場所、人数と金額、予約者とキャンセル期限 の順。これ以上の情報は詳細画面に出す。
- キャンセル期限は、間近なら色付き、過ぎたら薄く「キャンセル期限超過」。
- 中止・終了・行かないは、チケット全体を薄くする。

## 動き

- 動きは 0.2〜0.3 秒。止まる直前にゆっくりになる動き（`cubic-bezier(0.2, 0.8, 0.2, 1)`）を使う。
- 下にスクロールすると上のバーと下のメニューを隠し、上に戻すと出す。画面の上端近くでは必ず出す。
- 高さが変わるもの（カレンダーを縮めるなど）は、突然切り替えずに高さをなめらかに変える。
- 押した手応えは、記号が軽く弾む程度にとどめる。揺らす・点滅させる動きは使わない。
- 「動きを減らす」設定の人には動きを止める（`prefers-reduced-motion`）。

## カレンダー

- カレンダーの今日（当日）は、日曜・祝日（赤）と混ざらないよう文字色は変えず、細い枠線（輪）で表す。選択中の日付は黒丸で反転する。

## 言葉

画面に出す言葉は [用語集](glossary.md) に従います。英語の見出しやメニュー名は使いません。

## 確かめ方

- `npm test` に、決まりが崩れていないかを見るテスト（[design.test.ts](../apps/liff/test/design.test.ts)）があります。色・文字の大きさ・角丸を直接書いたり、インラインスタイルを増やしたりすると落ちます。
- 見た目を変えたら、モック（`liff-mock`、スマホからは `liff-mock-lan`）で、スマホ幅と広い画面、ライトとダークを見ます。
- 画面に関わる変更は、PR を出す前に、管理者にモックで触ってもらい OK をもらいます。

## この決まりを直すとき

1. 今ある部品やトークンで足りないか、もう一度確かめる。
2. 足りなければ、この文書の当てはまる所に「何を・どこで使うか」を足す。トークンなら `styles.css` の先頭にライトとダークの両方の値を足す。
3. 足した決まりを使って画面を作る。
