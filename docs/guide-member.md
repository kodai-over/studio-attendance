# メンバー向けの使い方（案内文）

グループに送る文面です。友だち追加やログインは不要です。

---

スタジオ練の募集がBotから届くようになりました📣

**回答する**
「参加者募集」のメッセージの「回答」またはアプリ下の「RSVP」タブから画面が開きます。予約情報ごとに ○（行く）△（未定）✕（行かない）を選んでください。募集メッセージの「回答」から開いたときは選んだ時点で記録されます。アプリ下の「RSVP」タブから答えるときは、「回答を反映してグループに伝える」または「回答を反映して完了」を押すとまとめて反映されます。
回答したことをグループに知らせたいときは、「回答を反映してグループに伝える」を押すと、「○ 11/1(日) 行きます／△ 11/2(月) 未定です」のような1通が自分の発言として送られます。「回答済」タブで回答を変更したときは「・11/1(日): 未定 → 行く」のように変更前と変更後が分かる形で送られます。送る文はその場で書き換えることもできます。
知らせなくてよいときは「回答を反映して完了」を押せば回答が反映されます（画面はそのまま留まります）。
複数のグループに所属している場合は、画面上部のグループ切り替えからグループごとに回答・送信できます。
まだ決められないときは「未定」にしておき、決まったら「RSVP」の「回答済」タブから選び直せばOKです（未定は人数・割り勘には数えません）。

**今後の予約情報を見る**
- グループで「予約情報」とだけ送ると一覧が返ってきます
- アプリの「予定」で予約情報を押すと、参加者（行く・未定・行かない）・1人あたりのスタジオ代・部屋の広さ・カレンダー追加を見られます。回答や変更は「RSVP」から行えます。一覧の金額はスタジオ代の合計です
- アプリの「行く」タブで（行く予約情報は日付の部分が黒くなります）、自分が行く予約情報だけ確認できます
- アプリに出るのは、所属グループに募集された予約情報と、自分が予約・回答した予約情報です。所属グループの予約情報が出ないときは、そのグループの募集メッセージの「回答」から一度開いてください

**カレンダーに入れる**
「回答」で開いた画面（RSVP）で予約情報を押し、「カレンダーに追加」から Googleカレンダー／iPhoneのカレンダーに入れられます。

**グループにいない人を誘うとき**
予約者に頼んでください。予約者はアプリの「募集」で予約情報を開き、「ゲスト」に名前を入れるか、「参加リンク」をコピーして本人に送れます。本人はブラウザで名前を入れて「行く」を押すだけです。

**名前が分かりにくいとき**
アプリの「アカウント」から一覧に出る表示名を変えられます。

**メニュー**
スタジオ練出欠管理（Bot）を友だち追加すると、トーク画面の下に「予定確認」「予約登録」「ブラウザで開く」のボタンが出ます。予定・募集・RSVP・アカウントは、アプリの画面下のナビからも選べます（登録は「募集」の右上の「＋」からも可能）。

**予約情報を登録する**
スタジオを予約したら、誰でも登録できます。予約画面のスクショか予約内容の文章をBotに送るか、アプリの「募集」の右上の「＋」から入力してください。

**改善要望**
アプリの「アカウント」画面にある「要望を送る」から、こうなったら便利・ここが使いにくい、などを送れます。送った要望は名前と一緒に管理者だけに届きます。
